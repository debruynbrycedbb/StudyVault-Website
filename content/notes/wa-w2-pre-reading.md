# Lesson 2 — Pre-reading notes: UX metrics

**Course:** Web Analytics · MX013

## Core behavioural UX metrics (automated tracking)

- **Task success rate (TSR)** — the percentage of users who successfully complete a defined task, e.g. finishing a checkout or filling out a form. Widely considered the ultimate baseline UX metric.
- **Time on task (ToT)** — the exact duration a user spends to complete a workflow. Lower time means better efficiency (productivity tools); higher time might signal higher engagement (content apps).
- **User error rate (UER)** — the average number of mistakes a user makes while attempting a task. Higher error rates pinpoint exactly where a layout or form field is confusing.
- **Drop-off / abandonment rate** — the percentage of users who begin a structured user flow but quit before completing the step.

## Core attitudinal UX metrics (user feedback)

- **System Usability Scale (SUS)** — a 10-item questionnaire yielding a single usability score from 0–100. A score above **68** is considered average; anything above **80** is considered world class.
- **Single Usability Metric (SUM)** — mathematically combines task success, time on task and satisfaction score into a single composite percentage to measure overall dashboard performance.
- **Customer Effort Score (CES)** — a one-question metric asking "How easy was it to interact with our product today?", scored 1–7.
- **Net Promoter Score (NPS)** — measures long-term customer loyalty by asking how likely a user is to recommend the product to others. Widely used by executives, but a lagging indicator of UX quality compared to CES.

| Metric | Type | Scale / unit | Better when |
|---|---|---|---|
| TSR | Behavioural | % of users | Higher |
| ToT | Behavioural | Time | Lower for productivity tools; higher can mean engagement for content apps |
| UER | Behavioural | Errors per task | Lower |
| Drop-off | Behavioural | % of users | Lower |
| SUS | Attitudinal | 0–100 (68 average, 80+ world class) | Higher |
| SUM | Attitudinal (composite) | % | Higher |
| CES | Attitudinal | 1–7 | Easier |
| NPS | Attitudinal | Likelihood to recommend | Higher (lagging indicator) |

## CUPID score

- **Convenience** — communicating with your shoppers at the optimum time.
- **Understanding** — how effectively your digital platform gathers and analyses user intent.
- **Personalisation** — tailoring the browsing layout, product grids and promotions to individual user profiles instead of a static store.
- **Intimacy** — measuring customer emotional trust, brand connection and transparency. Tracks post-purchase engagement, responsive customer resolution systems and active review submission loops.
- **Data** — the foundational strategy for capturing, cleansing and leveraging customer signals cleanly. Maps out how efficiently you use conversation data layers without adding code bloat that impacts page response time.
