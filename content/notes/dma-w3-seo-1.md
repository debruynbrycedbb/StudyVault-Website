## What is SEO?

> Search engine optimisation is the process of improving a website's visibility in the **organic** results of different search engines.

- Methods, strategies, techniques and tactics used to increase website traffic by achieving high positions in search engine results (Google, Bing, Yahoo and others).
- Optimising online visibility in organic results across websites, social channels, blogs, press articles and multimedia content.
- SEO involves highly technical work, but **content marketing and social media are central to it**.

## Search engines by country

**Statcounter** shows search engine market share by country and time period. Use it to choose which search engines to target in each market.

## How do users search? User intent

| Intent | Example query |
|---|---|
| Transactional | Buy iPhone X |
| Informational | iPhone X features |
| Navigational | Apple iPhone X (a destination in mind: Apple's website) |
| Multimedia | iPhone X video |
| Local | iPhone X store Barcelona |
| Ambiguous | iPhone X |

The SERP shows results in many formats (organic, ads/shopping, knowledge graph, vertical results such as images and video). Vertical search engines (images, video, news…) each rank their own results.

## General SEO concepts — the path to rankings

**1) CRAWL → 2) INDEX → 3) RANK**

1. **Crawl:** search engine bots discover the page.
2. **Index:** the page is stored in the search engine's index.
3. **Rank:** the page is ordered in the results for a query.

**A user's view vs what Google sees:** press **Ctrl + U** in the browser to view the page source (e.g. `view-source:https://bypets.com/`). Google reads the code, not the design.

## On-page (on-site) optimisation factors

**The keyword concept:** each page on our website should have a search term or keyword that we want it to rank for — a **target keyword**. This keyword should appear in specific parts of the page. This is part of on-site optimisation.

On-site factors:

- Search intent
- Keywords
- Title
- H1
- H2–H3
- Images (title)
- Images (alt)
- Text
- URL structure
- Internal linking
- Meta description (no longer a ranking factor)

SEO browser extensions help check these factors on any page.

## The keyword

- The search terms we want to rank for.
- **Probably the most important part of SEO.**
- Understanding how people search for us.
- **Principle: one keyword, one landing page.**

### Keyword selection

- Many tools are available; start with brainstorming.
- Aim for the **best balance of ranking difficulty and potential traffic**.

### Keyword tools shown in class

| Tool | What it shows |
|---|---|
| Google Keyword Planner | Seed keywords → suggested keywords, average monthly searches, trend over the last 3 months |
| Semrush | Suggested keywords, monthly search volume range, keyword difficulty |
| Google suggestion tool (autocomplete) | What people type after your seed term |
| Ubersuggest (Neil Patel) | Keyword ideas and volumes |
| Others | Wordtracker, Microsoft Keyword Research Tool, Keyword Discovery, Google Trends |
